# Web Design Course - Practical Outline

This is the practical side of the Web Design course from Modern Specialized University. The course covers foundational web development skills through laboratory chapters.

## Chapter Structure

### Chapter 1: Introduction to Web & HTML Basics

**Topics Covered:**

- The internet and the web
- Web browsers and their functions
- Internet service providers and Domain Name Servers
- URLs: structure and function
- Overview of web page creation process
- HTML vs CSS vs JavaScript
- How browsers display web pages
- HTML Documents, Syntax, Elements, and Tags

**Practical Exercise:**
Students will create their first HTML document with proper structure, including DOCTYPE, html, head, and body tags. They'll create a personal profile page with headings and paragraphs.

**Skills:**

- Understand web fundamentals
- Write valid HTML5 documents
- Use basic HTML tags correctly

---

### Chapter 2: HTML5 - Headings, Paragraphs & Text Formatting

**Topics Covered:**

- Organizing page content
- HTML Attributes
- Heading and paragraph tags
- Text formatting (bold, italic, emphasis, strong)
- Styles in HTML
- Colors: Text color and Background color

**Practical Exercise:**
Create a blog post or article page using semantic HTML headings, paragraphs, and text formatting. Apply inline styles for colors and basic styling.

**Skills:**

- Use heading hierarchy correctly
- Format text appropriately
- Apply basic color styling
- Understand semantic HTML

---

### Chapter 3: HTML5 - Images, Links & Media

**Topics Covered:**

- Displaying images and other media
- Adding Links
- Favicons
- HTML5 media elements overview
- Video and Audio integration
- YouTube embedding
- Responsive web design fundamentals

**Practical Exercise:**
Create a multimedia portfolio page with images, hyperlinks to other pages, a favicon, and embedded video content. Build navigation between multiple pages.

**Skills:**

- Insert and format images
- Create internal and external links
- Embed multimedia content
- Understand responsive design basics

---

### Chapter 4: HTML5 - Tables & Structured Data

**Topics Covered:**

- Tables: structure and purpose
- Table elements (thead, tbody, tfoot)
- Table styling considerations
- Text-level semantic elements
- Data organization

**Practical Exercise:**
Create a schedule or data table (like a class timetable, price comparison, or sports statistics). Format the table with proper semantic structure.

**Skills:**

- Build well-structured HTML tables
- Understand when to use tables
- Organize tabular data semantically

---

### Chapter 5: HTML5 - Forms & User Input

**Topics Covered:**

- Building forms to collect user input and feedback
- Form elements (input, textarea, select, button)
- Form attributes (name, type, placeholder, required)
- Accessibility in forms
- Input validation basics

**Practical Exercise:**
Create a functional contact form or registration form with various input types (text, email, password, checkbox, radio, textarea). Style the form and test submission.

**Skills:**

- Build accessible HTML forms
- Use appropriate input types
- Understand form validation basics

---

### Chapter 6: HTML5 - Lists & Content Organization

**Topics Covered:**

- Unordered lists (ul, li)
- Ordered lists (ol, li)
- Description lists (dl, dt, dd)
- Nested lists
- Semantic use of lists for navigation

**Practical Exercise:**
Create a product catalog page or course syllabus using different list types. Build a navigation menu using semantic list markup.

**Skills:**

- Use lists semantically
- Create navigation structures
- Organize hierarchical content

---

### Chapter 7: CSS Basics - Selectors, Colors & Backgrounds

**Topics Covered:**

- CSS Role and Syntax
- Selectors (element, class, ID, attribute)
- Colors and color models
- Backgrounds and background images
- External stylesheets
- CSS validation

**Practical Exercise:**
Take the HTML from previous chapters and style it with external CSS. Apply color schemes, background gradients, and use various selectors to target elements.

**Skills:**

- Write valid CSS
- Use selectors effectively
- Apply colors and backgrounds
- Link external stylesheets

---

### Chapter 8: CSS Intermediate - Box Model & Typography

**Topics Covered:**

- Borders
- Margins
- Padding
- Height and Width
- Box model understanding
- Text and fonts
- Font properties (family, size, weight, style)
- Line height and letter spacing

**Practical Exercise:**
Create a multi-column layout using CSS margins and padding. Style typography to create visual hierarchy. Build a card-based design component.

**Skills:**

- Understand and apply the box model
- Control spacing and sizing
- Master typography styling
- Create consistent layouts

---

### Chapter 9: CSS Advanced - Effects & Animation

**Topics Covered:**

- Icons (Font Awesome, Bootstrap Icons)
- CSS Transitions and Transforms
- CSS Animations (keyframes)
- List styling
- Table styling
- Hover effects and interactivity

**Practical Exercise:**
Create an interactive portfolio or product showcase with animated elements, transitions on hover, icon integration, and keyframe animations.

**Skills:**

- Apply CSS transitions and animations
- Use icon libraries
- Create interactive CSS effects
- Enhance user experience with motion

---

### Chapter 10: JavaScript Basics - Interactivity & Functionality

**Topics Covered:**

- JavaScript Role in web design
- JavaScript Syntax
- Variables and data types
- Input and output (console, alert, prompt, DOM manipulation)
- Basic statements and operators
- Event handling basics

**Practical Exercise:**
Create an interactive web page with JavaScript that responds to user input. Build a simple calculator, form validator, or interactive quiz. Use DOM manipulation to update page content dynamically.

**Skills:**

- Write basic JavaScript code
- Use variables and data types
- Implement event listeners
- Manipulate the DOM
- Create interactive user experiences

---

## Learning Progression

The 10 chapters follow a logical progression:

1. **Weeks 1-3**: HTML Fundamentals (Chapters 1-6)
2. **Weeks 4-7**: CSS Styling (Chapters 7-9)
3. **Weeks 8-10**: JavaScript Interactivity (Chapter 10)

Each chapter builds upon previous knowledge, starting with structure (HTML), adding presentation (CSS), and finally introducing behavior (JavaScript).
